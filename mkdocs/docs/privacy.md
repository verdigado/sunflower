# Datenschutz

## Cookies
Das Theme setzt keine Cookies.

## Daten von fremden Servern
Das Theme bindet auf Wunsch bei Termine einen Landkarte ein. Wer diese Landkarte sehen möchte, 
muss zuerst einen Button klicken und erhält einen Link zu den Datenschutzrichtlinien des fremden
Servers.

## Kontaktformular
Unter dem Kontaktformular steht ein Hinweis zur Datenverarbeitung. Er verlinkt auf die Seite,
die in WordPress unter *Einstellungen → Datenschutz* als Datenschutzerklärung hinterlegt ist.
Ist dort keine Seite gesetzt, bleibt der Begriff unverlinkt.

Der Text ist bewusst nicht pro Formular editierbar. Die Formulierung hat rechtliche Bedeutung,
und eine zentrale Fassung erreicht alle Seiten, sobald sie korrigiert wird.

Eine Zustimmung per Checkbox verlangt das Formular nicht. Die Hintergründe dazu erklärt der
Artikel [Muss der Datenschutzerklärung zugestimmt
werden?](https://www.dr-datenschutz.de/muss-der-datenschutzerklaerung-zugestimmt-werden/).

## Datenschutzhinweise
Wer das Theme verwendet, muss wegen des Theme die eigenen Datenschutzrichtlinien nicht anpassen.
Das gilt natürlich nicht, wenn man eigene Anpassungen vornimmt oder Plugins verwendet.
Die üblichen Datenschutzvorkehrungen rund um WordPress bleiben davon unberührt.
